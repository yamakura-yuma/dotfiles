`session-retro` スキルに従って、このセッションの振り返りをしてください。

対象: $ARGUMENTS

（空なら、このセッション全体を対象にしてください。）

手順はスキルにあるとおりですが、要点だけ:

1. **学びがあったかを先に判定する。** 一度きりの話、既存のルールやスキルが既に言って
   いること、今後の振る舞いを変えないものは、拾わない。無理に何か書き出さないこと。
2. 学びがあったなら、**どのリポジトリでも真か**を判定して置き場所を決める。共通なら
   `makura-agents/.apm/`、このリポジトリだけなら `<repo>/.apm/`。共通側に倒す誤りは
   高くつく（合わないリポジトリにまでルールを押しつけることになる）。
3. **昇格したら、元のメモリファイルは消す。** 両方残すと、毎プロンプトの費用を重複して
   払ったうえで、いずれ片方が古くなる。

memory は下書き、git が正本。memory は絶対パスで鍵が引かれるので、リポジトリを移動
すれば取り残され、worktree には引き継がれず、他のホストには届かない。リポジトリに
置いたものだけが、その全部を越える。

置き場所を変えたら `apm install --target claude` で配備し直し、`.agent/verify.sh` を
実行してから、ソースの変更をコミットすること。
