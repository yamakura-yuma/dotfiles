`core-retro` スキルに従って、このセッションの振り返りをしてください。

対象: $ARGUMENTS

（空なら、このセッション全体を対象にしてください。）

振り返りは「何をしたか」の要約ではありません。**次回の環境をどう変えるか**の提案です。
手順はスキルにあるとおりですが、要点だけ:

1. **機械的に判定できるものは、文章ではなく検査にする。** `make ci` にターゲットを
   足せば済む話を、ルールやスキルの散文にしないこと。
2. 判断が要るものだけ、置き場所を決める。どのリポジトリでも真なら
   `core-principal/.apm/`、このリポジトリだけなら `<repo>/.apm/`。共通側に倒す誤りは
   高くつく（合わないリポジトリにまでルールを押しつけることになる）。
3. **何も無かったカテゴリは、無かったと言う。** カテゴリごとに findings をでっち上げた
   振り返りより、短い振り返りのほうが役に立ちます。
4. **昇格したら、元のメモリファイルは消す。** 両方残すと、毎プロンプトの費用を重複して
   払ったうえで、いずれ片方が古くなる。

memory は下書き、git が正本。memory は絶対パスで鍵が引かれるので、リポジトリを移動
すれば取り残され、worktree には引き継がれず、他のホストには届かない。リポジトリに
置いたものだけが、その全部を越える。

置き場所を変えたら `apm install --target claude` で配備し直し、`make ci` を実行して
から、ソースの変更をコミットすること。
